# منصة كسب اليمن (Kasb Yemen) — للمهام المصغرة والربح الرقمي

منصة متكاملة قابلة للإنتاج (Production-Ready) مصممة خصيصاً للسوق اليمني، تتيح للمستخدمين في كافة المحافظات اليمنية إنجاز مهام رقمية مصغرة، كسب الريال اليمني (YER)، وتجميع الأرباح في محفظة رقمية داخلية وسحبها مباشرة عبر شبكات الصرافة والبنوك اليمنية (بنك الكريمي، شبكة النجم، محفظة جوالي، ومحفظة ون كاش).

## 3. محرك الأمان المالي وسجل المعاملات (Financial Ledger Engine)

- **دفتر أستاذ غير قابل للتعديل (Immutable Financial Ledger):** كل حركة مالية (مكافأة مهمة، حجز سحب، استرجاع سحب، مكافأة إحالة) تنشئ سجلاً فريداً برقم معرف وقيمة سابقة وقيمة جديدة.
- **الحجز الذري للسحوبات (Atomic Balance Reservation):** عند طلب السحب، يُحجز المبلغ فورياً من الرصيد المتاح وينتقل للرصيد المعلق لمنع السحب المزدوج (Double Spending).
- **الاسترجاع التلقائي عند الرفض:** إذا رفض المشرف طلب السحب، يُعاد المبلغ المحجوز كاملاً وفورياً إلى محفظة المستخدم مع توثيق السبب وإشعار المستخدم.
- **منع الرصيد السالب:** لا يمكن لأي عملية أن تؤدي إلى رصيد أقل من الصفر.
- **وحدات صحيحة بالريال اليمني (Integer Minor Units):** جميع العمليات الحسابية تتم بالأعداد الصحيحة دون أخطاء الفاصلة العائمة.

## 4. شبكات الدفع والسحب المعتمدة في اليمن

1. **بنك الكريمي للتمويل الأصغر الإسلامي:** حساب مميز أو إرسال صرافة بالاسم ورقم الهاتف.
2. **شبكة النجم للحوالات المالية الفورية:** حوالة بالاسم الرباعي ورقم الهاتف قابلة للصرف من أي نقطة صرافة في اليمن.
3. **محفظة جوالي (كاك بنك):** تحويل مباشر إلى رقم المحفظة المسجل.
4. **محفظة ون كاش (OneCash):** إيداع رقمي فوري.
